| D-10 | 11-14 | Feature table per astronaut: RAW Bias = that person's mean over the first 1200 s (pre-mission baseline analogue) + train population offset. Model table shared by all. First 1200 s never scored. | Inter-person level differences (EDA, skin temp) would otherwise swamp the model. |
| D-11 | 11-14 | 1 % i.i.d. packet loss per source added to ALL replays (train/val/test). **Assumption.** | Real data has zero gaps; without loss the model would treat any single dropped packet as a fault. |
| D-12 | 11-14 | Matched false-alarm budget = 0.1 % of validation ticks (about 3.6 alarm-seconds per hour) for all three detectors. | Rule 2. |
| D-13 | 11-14 | **Vendor `DIFF` not used.** It implements counter semantics: `(Raw - Prev) & mask` as unsigned, so a 1-LSB HR drop becomes +65535 (found when the train mean of HR-DIFF came out at 15 067 raw LSB). Correct for monotonic counters (its purpose), wrong for signed physiology. A signed-difference transform would be new C code: future work. | Found by checking feature means, not by trusting the score. |
| D-14 | 11-14 | PPG-DaLiA pickle wrist ACC is already in g (median norm 1.013), not E4 raw 1/64 g. | Checked on S1. |
| D-15 | 11-14 | HOLD only on HR and RMSSD. Activity (ENMO clipped at 0 at rest), skin temp and EDA (coarse sensor resolution) legitimately stay constant for minutes (validation activity-HOLD max 22 717 LSB vs train 5 230). Final F = 9: RAW x5, HOLD x2, AGE x2 -> 162-byte int8 table. | HOLD is only meaningful where the healthy signal always moves. |
| D-16 | 11-14 | Feature scaling: RAW maps train p99.9 of abs(x - bias) to 4000 LSB; HOLD/AGE map the train MAXIMUM to 4000 (they are heavy-tailed counters, p99.9 was 1-3 ticks and made a 2-tick packet gap look like a fault). | Measured, see scripts/debug_model.py output. |
| D-17 | 11-14 | Counter features (HOLD/AGE) scaled so their train max maps to 400 LSB (RAW: p99.9 maps to 4000), ridge 3e-2. Chosen because, on **validation**, every top-0.1 % score was a packet-loss spike in a counter; with this setting the top validation scores come from HR RAW. | Thresholds must not be set by packet loss. |
| D-18 | 11-14 | Range check uses **personal** limits (baseline + train delta range), like CrewWatch's personal feature tables. Event detection is reported next to its **chance level** (P(alarm) in a fault-free window of the same length). Brady plateau gets AR(1) jitter. | A fair comparison, and an honest metric for long fault windows. |
| D-19 | 11-14 | Second model instance SLOW = same shape on the vendor flight window mean (64 ticks). Added after seeing test results, no detection gain, disclosed in eval/READING.md. **Model frozen after this.** | Avoid tuning on the test set. |
| D-20 | 11-14 | Headline finding changed: CrewWatch's measured value is sensor-health faults + fewer false alarms on new people; types 3–4 not detected above chance by any method. Pitch must follow the data (ROADMAP §3.3: "write what comes out"). | Rule 2. |
